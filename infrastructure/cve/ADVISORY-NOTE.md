# Offline advisory reference

Apache identifies the affected Maven artifact for CVE-2021-44228 as `org.apache.logging.log4j:log4j-core`. For the Java 8 release branch relevant to this exercise, compare releases from 2.13.0 inclusive to 2.15.0 exclusive. Apache lists 2.15.0 as the first corrected release on that branch for this specific CVE. The Java 6 and Java 7 maintenance branches have different cutoffs. The API artifact alone does not establish presence of the affected implementation. This note summarizes the Apache entry checked on 19 November 2026 and can be used without internet access. [Apache Logging Services security advisory](https://logging.apache.org/security.html#CVE-2021-44228)
